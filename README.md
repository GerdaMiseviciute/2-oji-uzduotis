# Objektinis-programavimas
Programa, kuri apskaičiuoja studentų galutinius rezultatus pagal vidurkį ir pagal medianą. Pagal meniu vartotojas gali pasirinkti, ar jis nori visus studentų duomenis įrašyti pats, ar kad dalis studentų duomenų (studentų pažymius) arba visi duomenys (vardus, pavardes ir pažymius) būtų generuojami.
Parašytas kodas realizuotas vektoriais (main.cpp) ir masyvais (main1.cpp).

1.
1000 dydžio failą sugeneruoti užtruko 0.0090545 s
10000 dydžio failą sugeneruoti užtruko 0.0484215 s
100000 dydžio failą sugeneruoti užtruko 0.46605 s
1000000 dydžio failą sugeneruoti užtruko 4.70223 s
10000000 dydžio failą sugeneruoti užtruko 48.4771 s
